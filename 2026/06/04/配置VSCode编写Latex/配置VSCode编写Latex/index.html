环境信息

我的开发环境如下：

  • 操作系统：Windows
  • 编辑器：VS Code
  • LaTeX 发行版：TeX Live
  • VS Code 插件：LaTeX Workshop
  • 编译器：XeLaTeX

选择 XeLaTeX 的主要原因是其对中文支持较好，能够直接使用 UTF-8 编码编写中文文档。
